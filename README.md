# nikodemus.dev — personal playground

A single-page personal site built with React, TypeScript, and Tailwind.

It exists purely for fun: a choose-your-own-adventure bio, a handful of absurd interactive toys, and a few things you're meant to stumble upon rather than be told about.

## Stack

- React + TypeScript, Vite
- Tailwind CSS 
- Framer Motion
- Matter.js
